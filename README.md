# Perfecto Ready Stock Ads

Plugin WordPress/WooCommerce khusus untuk manajemen dan optimasi tampilan *landing page* serta iklan *ready stock* pada etalase e-commerce Perfecto. Dikembangkan untuk mendukung ekosistem multi-brand ISA Group.

## Fitur Utama
* Tampilan katalog *ready stock* yang responsif dan disesuaikan dengan *styling* visual Perfecto (Logo Gold).
* Tata letak *landing page* khusus untuk menyoroti produk andalan (Cargo, Chinos, Cutbray, Loose, Rok, Slim).
* Integrasi langsung untuk mempermudah alur pemesanan (termasuk dukungan *checkout* via WhatsApp).

## Struktur Direktori
* `/assets/` - Berisi file statis seperti CSS, JS, gambar, video, dan aset visual produk.
* `/includes/` - Berisi *core logic* plugin, pengaturan admin, dan pengelolaan katalog.
* `/templates/` - Berisi struktur *front-end* untuk *landing page* dan tata letak konten.

## Instalasi
1. Unduh repositori ini.
2. Ekstrak dan pastikan nama folder adalah `perfecto-ready-stock-ads`.
3. Pindahkan folder ke direktori `wp-content/plugins/` di instalasi WordPress Anda.
4. Masuk ke *dashboard* admin WordPress, lalu navigasi ke menu **Plugins**.
5. Cari **Perfecto Ready Stock Ads** dan klik **Activate**.
